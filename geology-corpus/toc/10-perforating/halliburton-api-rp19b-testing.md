# halliburton-api-rp19b-testing

**Covers:** A single-section technical reference on API RP19B shaped-charge perforator testing procedures (Sections 1-6) as documented by Halliburton's Jet Research Center.

**Authoritative for:** distinguishing API RP19B Section 1 through 6 test types and what each measures, which test procedure yields penetration into stressed rock at simulated downhole conditions (Section 4 vs unstressed concrete targets), standard concrete/cement target penetration measurement methodology (Section 1), tests for gun and casing deformation, burr height, and gun swell after detonation (Section 2), flow-performance and core-flow-efficiency test framing for perforating charges

**Not good for:** actual charge performance numbers for specific commercial gun systems or competitor products, perforation skin, productivity-ratio, or nodal-analysis calculations for a given completion, perforating gun selection, shot density, or phasing design decisions for a specific well, formation damage, underbalance/overbalance surge design, or dynamic underbalance modeling, rock mechanics or reservoir characterization of any named field or basin, non-perforating completion topics; earlier or superseded API RP43 test conventions

**Scope:** Vendor-authored (Halliburton/Jet Research Center) summary of an API recommended practice; scope is laboratory test methodology only, not field results, and it is basin- and formation-agnostic. Reflects one snapshot of the RP19B standard, so verify against the current API edition before citing section numbering or acceptance criteria. Only the perforating section of the source document is indexed here.
